# Артем Мута — портфолио

Статический сайт: главная `index.html` + пять страниц кейсов в `cases/`. Без зависимостей — только Node для пересборки кейсов.

## Запуск локально

```bash
npx --yes http-server . -p 5173 -c-1
```

Открыть http://localhost:5173.

## Деплой

Сайт живёт на **https://artemmdesign.ru** — GitHub Pages из ветки `main` (корень репозитория), домен задан файлом `CNAME`, HTTPS — Let’s Encrypt от GitHub. DNS у Sprinthost: 4 A-записи `@` на 185.199.108–111.153 и CNAME `www` → `artemdesignerwork-dev.github.io`.

Обновить сайт: поправить файлы (и `node build-cases.mjs` после правок в `content/`) → `git push` в `main`. Через минуту изменения на домене.

Старые адреса на Vercel (`portfolio-wfzd.vercel.app`, `artemmuta.vercel.app`) постоянно перенаправляют на новый домен — правило в `vercel.json`.

## Структура

| Что | Где |
|---|---|
| Главная | `index.html` |
| Страницы кейсов | `cases/<slug>.html` — **генерируются**, руками не править |
| Тексты кейсов | `content/<slug>.md` — Markdown + шапка (title, lead, role, platform, focus, hero, order) |
| Сборка кейсов | `node build-cases.mjs` — после любой правки в `content/` |
| Стили (общие для всех страниц) | `assets/site.css`; цвета, радиусы, шрифт — переменные в `:root` |
| Картинки главной | `assets/web/` |
| Картинки кейсов | `assets/cases/<slug>/` (веб-версии, ≤ 2000px) |
| Оригиналы из Notion | `source/` — не используются сайтом, нужны сборщику только для размеров |
| Шрифт Golos Text | `assets/fonts/` — self-hosted, переменный 400–900 |
| Дизайн-система | `DESIGN.md` |

## Разметка в `content/*.md`

- `#`, `##`, `###` — заголовки разделов (уровни не пропускаются автоматически).
- `![подпись](файл.jpg)` — картинка; подряд идущие картинки собираются в сетку. Телефоны — 4 в ряд, скриншоты веб-страниц — 2 в ряд, одиночный экран встаёт рядом с текстом.
- `![…](файл.jpg){tall}` — длинный скриншот, прокручивается внутри рамки. `{strip}` — ряд экранов конкурентов в рамках одинаковой высоты. `{wide}` — десктопный экран на всю ширину колонки. `{page}` — скриншот веб-страницы, даже если исходник узкий (2 в ряд, длинный обрезается).
- `:::callout … :::` — выделенный блок (светло-синий). `:::cols … :::` — сетка принципов из `###` + текст.
- `## Персона …` — блок персоны; его `###` становятся колонками.
- Шапка: `heroPos: center top` — если обложку надо кадрировать по верху.

## Чего не хватает (не удалось выгрузить из Notion)

- Mobile Rental: схема **User Flow** (вложение не отдаётся API).
- Equipment Rental: картинки `content_(1).jpg`, `Frame_315_(1).jpg` — раздел «Technical Visualization» без иллюстрации.
- SaaS Subscription: собственная обложка `hero_(5).jpg` — вместо неё планшет с главной.
- Картинки «Project Snapshot» — не используются.

Чтобы добавить: положить файл в `assets/cases/<slug>/`, вписать `![подпись](файл.jpg)` в `content/<slug>.md`, выполнить `node build-cases.mjs`.
